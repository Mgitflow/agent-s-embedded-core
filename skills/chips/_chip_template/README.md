# 芯片包目录 · 最小原型

一份芯片肖像 = 一个目录（目录名 = 芯片名）。**最少**需要两个文件：

| 文件 | 作用 |
|---|---|
| `manifest.yaml` | 芯片名 + 系列 + HAL 库名（决定怎么生成） |
| `profile.json` | 引脚映射 `pin_map` + 复用功能 `af_map` |

> **这是最小原型**。原项目有更完整的结构（manifest 有继承/时钟/电压/外设清单 20+ 字段，
> profile 有 13 顶层字段），见 `docs/DATA_SPEC.md` 参考——**但你不必照搬**，够用就行，
> 爱咋做咋做。骨架 `chip_gateway` 扫目录自动识别，字段对不上会显式报错，不会静默。
