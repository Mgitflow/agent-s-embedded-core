# 芯片包目录

一份芯片肖像 = 一个目录（目录名 = 芯片名），内含 4 类文件：

| 文件 | 作用 | 字段说明 |
|---|---|---|
| `manifest.yaml` | 芯片元信息 + 继承关系 + 外设清单 | 见 `docs/DATA_SPEC.md` §1 |
| `profile.json` | 芯片画像（时钟树 / 引脚 / AF / 特殊引脚 / DMA） | §2 |
| `pin_map.json` | 引脚映射（封装 → 每引脚复用信号） | §3 |
| `af_map.json` | 复用功能映射（信号 → 引脚 + AF 编号 + 默认引脚） | §4 |

> 本目录 `_chip_template/` 是**空模板**，展示「放什么、什么格式」，不含真实芯片数据。
> 接手者复制本目录改名，照字段说明填真实数据，骨架代码 `chip_gateway` 会自动扫描识别，
> **无需改代码**即可接入新的芯片肖像。
