# 开发板目录

一份开发板定型 = 一个目录（目录名 = 板子名），核心文件 `board.json`：

| 字段 | 作用 |
|---|---|
| `meta` | 板子名 + 绑定主控芯片（`mcu` 决定走哪套芯片肖像） |
| `oscillator` | 板载晶振（HSE/LSE 频率，时钟树基准） |
| `leds` / `keys` | 板载 LED / 按键的引脚（**板级定型，与芯片默认并列**） |
| `onboard_peripherals` | 板载资源（SPI Flash / 外部 SRAM / 蜂鸣器 等） |
| `codegen_rules` | 代码生成规则（如「按键启动门」「有源器件待机」） |

> 开发板与芯片是**并列**关系：芯片肖像给「芯片默认引脚」，开发板给「板载定型引脚」。
> 两者井水不犯河水——提到板子走板子那套，提到芯片走芯片那套。

> 本目录 `_board_template/` 是空模板，字段详细说明见 `docs/DATA_SPEC.md` §5。
