# 开发板目录 · 最小原型

一份开发板定型 = 一个目录（目录名 = 板子名），最少一个 `board.json`：

| 字段 | 作用 |
|---|---|
| `meta.mcu` | 绑定主控芯片（决定走哪套芯片肖像） |
| `leds` / `keys` | 板载 LED / 按键引脚（**板级定型，与芯片默认并列**） |
| `onboard_peripherals` | 板载资源（SPI Flash / 外部 SRAM / 蜂鸣器等） |

> **开发板与芯片是并列关系**：芯片肖像给「芯片默认引脚」，开发板给「板载定型引脚」，
> 井水不犯河水。这是最小原型——原项目 `board.json` 还有晶振/调试/电源/生成规则等字段，
> 见 `docs/DATA_SPEC.md` 参考，你不必照搬。
